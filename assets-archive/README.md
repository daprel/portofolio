# Assets Archive

Gambar yang **tidak dipakai** di website saat ini, disimpan di luar `public/` agar tidak ikut ter-deploy ke GitHub Pages. Folder ini tetap masuk repository (publik di GitHub), jadi jangan simpan dokumen pribadi di sini — gunakan `private/`.

Untuk memakai lagi sebuah file: pindahkan ke folder yang sesuai di `public/images/`, lalu panggil lewat `asset('images/...')` di `src/data/`.

```
gtx-laboratory/   kunjungan Lab GTX ke GMF
misc/             foto lama dari versi web sebelumnya (gudang & tea tasting)
organizations/    logo PTPN
research/         dokumentasi ICOEINS 2026 & halaman paper ICSMech 2026
```
